# 可配置自动登录 Chrome 插件

这是一个基于 Manifest V3 的谷歌浏览器扩展，用来在指定登录页打开时，根据你预先维护的配置自动填充账号、密码和附加字段，并按规则自动提交表单。

## 已实现功能

- 支持多条登录规则，适配多个系统或多个登录页面。
- 每条规则支持多个 URL 模式匹配，使用 `*` 通配符。
- 支持配置账号选择器、密码选择器、提交按钮选择器、表单选择器。
- 支持配置“已登录状态”选择器，避免重复提交。
- 支持配置附加字段 JSON，例如租户编码、二级组织等。
- 支持导入/导出所有规则。
- 支持弹窗查看当前页面是否命中规则，并手动重跑一次。

## 安装方式

1. 打开 Chrome 浏览器，进入 `chrome://extensions/`
2. 打开右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择当前目录：`D:\codexprojects\chrometools`

## 使用方式

1. 安装扩展后，点击扩展图标。
2. 打开“配置页”，新增一条规则。
3. 填写 URL 模式、账号/密码选择器和值、提交按钮或表单选择器。
4. 保存后访问目标登录页。
5. 页面加载并出现表单后，扩展会自动填充并提交。

## 示例

URL 模式：

```text
https://oa.example.com/login*
https://oa.example.com/sso/*
```

常见选择器：

```text
账号输入框：#username
密码输入框：#password
提交按钮：button[type="submit"]
已登录标识：.user-avatar
```

附加字段示例：

```json
[
  {
    "selector": "#tenantCode",
    "value": "acme"
  }
]
```

## 规则说明

- URL 模式支持 `*` 通配，例如 `https://*.example.com/*login*`
- 规则按列表顺序匹配，命中第一条后执行
- 配置了“已登录标识选择器”时，页面上存在该元素则不会重复登录
- 同一标签页同一页面默认只自动执行一次，避免循环提交
- 在弹窗点击“立即执行一次”可以强制再次运行

## 安全提示

当前版本为了保证自动登录可直接使用，账号密码保存在浏览器扩展本地存储中。这适合内网测试、演示或受控环境，但不适合高安全要求场景。

如果后续还要增强，建议继续增加：

- 主口令加密本地存储
- 规则分组、优先级和启停控制
- 从企业配置中心拉取规则
- 登录前增加人工确认或验证码流程
