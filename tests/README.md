# 本地测试用例

这个目录提供一个完整的本地联调用例，用来验证当前 Chrome 自动登录插件是否能：

- 匹配目标页面 URL
- 等待异步渲染的表单出现
- 自动填充账号、密码和附加字段
- 自动触发表单提交
- 在出现已登录标识后停止重复提交

## 文件说明

- `login-demo.html`
  一个本地模拟登录页，表单会延迟渲染，并在提交成功后显示 `.user-avatar`
- `local-config.json`
  可以直接导入扩展设置页的测试规则
- `server.js`
  零依赖本地静态服务器，默认地址是 `http://127.0.0.1:8787`

## 运行方式

1. 在项目根目录执行：

```bash
node tests/server.js
```

2. 打开 Chrome 扩展配置页，导入：

```text
tests/local-config.json
```

3. 访问：

```text
http://127.0.0.1:8787/login-demo.html
```

## 验证点

- 页面初始先显示加载态，约 1.2 秒后出现登录表单
- 插件应自动填充：
  - `#tenantCode` => `acme`
  - `#username` => `demo.user`
  - `#password` => `P@ssw0rd!`
- 插件应自动点击 `#loginButton`
- 成功后页面出现 `.user-avatar`
- 刷新页面后应再次自动登录
- 点击“同 Tab 退出并回到登录页”后，应再次自动登录

## 失败时排查

- 扩展没有动作：
  检查是否已导入 `local-config.json`，以及扩展是否处于全局启用状态
- 页面是空白或打不开：
  检查 `node tests/server.js` 是否正常运行
- 值填充了但没有提交：
  打开扩展弹窗，点击“立即执行一次”重试
- 页面提示登录失败：
  说明当前填充值与测试规则不一致，可以检查选择器或配置是否被修改
